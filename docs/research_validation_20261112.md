# ETF Insight — 데이터 확보 및 금융연구 검증 기록 (2026-11-12)

> 상태: 기능 브랜치에서 개발 중인 **확인 기록**. 코드 회귀 테스트와 실제 금융시장 데이터 검증, 공개 사이트 실사용 검증은 각각 다른 절차다. 검증되지 않은 데이터를 공식 실측자료라고 표현하지 않는다.

**주의:** 저장소의 1,190개 기본정보 수치는 포함된 메타데이터와 기존 회귀검사에서 확인한 값이며, 이는 실질분석 가능한 ETF 수가 아니다. 공개 웹서비스의 최신 시장 전종목 총수라고 단정하지 않는다.

## 개발 브랜치의 수정 범위

1. ETF별 자료 수준(기본정보만 / 자료부족 / 일부 분석 가능 / 제출 근거로 구조 분석 가능)을 분리
2. ETF별 종목비중 존재, NAV 열 표기, 분류 확인율, 기준일, 원본 SHA256 및 미확인 사유 관리
3. 공식 원출처 독립 확인 여부를 사용자 URL·파일명·비중 100% 합계로 **승격하지 않음**
4. 사용자 파일에서 여러 기업 분류표를 한꺼번에 병합. 동일 종목의 서로 다른 사업분류/날짜/출처는 충돌로 거부
5. ETF별 검증 상태와 전체 수치를 Excel `연구검증현황` 및 `ETF별자료상태` 시트로 출력
6. Python 3.11/3.12 GitHub Actions 및 합성 데이터 회귀검사로 코드 회귀를 확인; 이는 **실제 공식 ETF 데이터 교차검증을 대신하지 않음**

## 공식 자료의 확보 경로와 이용 제한

- **KRX 정보데이터시스템 및 Data Marketplace**: https://data.krx.co.kr/
- **KRX 홈페이지 이용약관**: https://data.krx.co.kr/contents/MDC/INFO/informationController/MDCINFO003.cmd
  - 제10조는 무단 자동수집·복제·배포, 제12조는 사전 허락 없는 복제·전송·배포 등을 제한한다. 비상업 학술연구라는 주장만으로 공개 사이트 데이터 재배포가 자동 허가되지 않는다.
- **KRX Open API 이용약관**: https://openapi.krx.co.kr/contents/OPP/INFO/OPPINFO002.jsp
  - API 이용 승인이 있더라도 제3자 제공 관련 제한을 별도로 확인해야 한다.
- **KRX KIND ETF 공시**: https://kind.krx.co.kr/
  - ETF 기초지수, 전략, 레버리지 여부, 운용사 등 공식 공시 확인용. 실제 편입종목 비중을 자동 보장하지 않음.
- **TIGER ETF 공식 자료실**: https://develop.investments.miraeasset.com/tigeretf/ko/reference/list.do
  - 운용사 구성종목·PCF 자료 확인 경로. 공개 자료 설명에는 1CU 기준 자료의 한계가 있으며 NAV 전체 구성과 임의 동일시하지 않는다.

위 링크는 검토할 **공식 제공 경로**이며, 이 브랜치가 해당 URL에서 ETF 전종목 NAV 데이터를 다운로드하거나 재배포 권한을 확보했다는 뜻이 아니다.

## 다음 검증에서 필요한 자료

1. 실제 분석 대상 ETF별로 **상품코드·상품명·기준일·비중 정의**가 명시된 원본
2. 완전성/총량 근거가 확인되는 NAV 전체 편입자료 또는 각 비중의 적용 범위
3. 기업별 사업과 국가·동일기업집단 식별에 관한 공식 공시의 URL·기준일
4. 실제 동일 날짜의 ETF A/B 구성비중을 대조한 기대값과 독립 재계산 결과
5. 필요 시 KRX/운용사의 공개 재배포 승인 범위 또는 사용자 전용 업로드 방식
6. 실제 배포된 Streamlit URL을 통한 파일 업로드·Excel 저장·세션 격리 수동 QA

마지막으로 **비중합계 100%는 산술 검사**일 뿐 원발행기관 인증, ETF 전체 편입 내역 보증, 재배포 허가를 의미하지 않는다.
