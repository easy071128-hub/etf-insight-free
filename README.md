# ETF Insight — KRX 구성비중 단독분석 지원 무료 웹버전

연구 주제: **「펀드·ETF의 실질 기반 재분류 및 투자자 안내 방안 제안」**

기존 GitHub 저장소 `easy071128-hub/etf-insight-free`와 Streamlit Community Cloud 무료 공개 앱을 유지하는 개선본입니다. 원본 KRX 자료나 개인 업로드 파일은 배포 ZIP에 넣지 않았습니다.

## 이번 버전에서 달라진 점

KRX에서 내려받은 구성종목 Excel 파일의 **`시가총액 구성비중`** 이 숫자로 제공되고 **비중 전체 합계가 100%±0.05%p 범위**이면, 기존과 달리 **`실질분석` 탭에서 ‘KRX 구성비중 단독 분석(ETF 미연결)’** 을 제공합니다.

- 실제 `data_5705_20261111.xlsx`: 구성항목 **22개(비현금 종목 21개·현금 1개)**, 숫자 **22개**, 원본 합계 **99.99%**.
- 계산 시 비중합계가 99.99%인 경우 **100%로 정규화**. 상위 1·3·5종목 **19.24%, 47.49%, 59.79%**, HHI(현금 포함) **989.47**, 판정 **‘집중’**.
- 현금 여부가 이름으로 명시된 항목만 상위 구성종목 집중도에서 제외합니다. 다른 종목의 **주식 여부를 추측하지 않습니다.**
- KRX 자료가 공식 자료라는 연구상의 전제는 존중하되, **시가총액 기준 비중을 ETF 순자산 대비 편입비중으로 바꾸어 표시하지 않습니다.**
- ETF 코드·기준일이 파일에 없으면 **특정 ETF에 자동 연결하거나 ETF 간 유사도에 합산하지 않습니다.** 검색된 TIGER 반도체와 종목이 일치한다는 이유만으로 자동 연결하지 않습니다.
- 구성종목 코드가 Excel에서 숫자로 저장되어 앞자리 0이 사라지는 문제 수정 (`5930` → `005930`, `660` → `000660`).
- 새 **단독 분석용 Excel 다운로드** 버튼: 원본 구성비중·비중 종류·계산값·해석상 한계 기록.

## 사이트 사용법

1. 기존 공개된 ETF Insight Streamlit 사이트에 접속합니다. 별도 프로그램 설치 불필요.
2. 원한다면 `data_0259_20261111.xlsx` 같은 **ETF 기본정보 목록**을 올립니다. **1,190개 검색**이 가능합니다.
3. `data_5705_20261111.xlsx` 같은 **숫자가 있는 KRX 시가총액 구성비중 Excel**을 올립니다.
4. **실질분석 → KRX 구성비중 단독 분석**을 확인합니다. ETF 목록과 연결되어 있지 않더라도 상위 1·3·5종목, 집중도 및 HHI가 표시됩니다.
5. **이 KRX 구성비중 분석을 Excel로 저장**을 눌러 결과물을 받습니다.
6. `data_0730_20261111.xlsx`처럼 구성비중이 전부 `-`인 자료는 27개 종목을 식별하지만 **정량 분석을 하지 않습니다**.

## 계산 방법과 한계

- 단일 비현금 종목 ≥20% 또는 상위 5 비현금 종목 ≥70%: **고집중**.
- 해당하지 않고 상위 3 비현금 종목 ≥40%: **집중**. 그 외: **분산**.
- HHI = Σ(전체 구성항목의 정규화 비중(%))². 현금이 명시되면 상위 종목 계산에서는 제외하고 HHI에는 포함합니다.
- 표 내부 비중 합이 약 100%라는 사실은 **표의 산술적 일관성**을 보여줄 뿐, **전체 ETF 편입종목·ETF 순자산 기준 비중·편입 기준일·ETF 코드**가 확인됐다는 뜻은 아닙니다.
- 현재 프로그램은 **시가총액 기준 단독 분석**과 **ETF 순자산 기준 스냅샷 분석**을 명확히 분리합니다. 미연결 자료를 ETF별 구조 유사도 계산에 섞지 않습니다.
- 산업, 국가, 기업집단 세부 분류와 5요소 종합 유사도 점수는 출처 데이터가 부족하면 **미산출**합니다.
- 업로드 파일 자체가 실제 KRX에서 발급된 원본인지 디지털 서명 등으로 독립 인증하지는 않습니다. 원본이라고 가정한 자료의 내용과 수치만 계산합니다.

## 기존 기능 유지

- ETF 기본정보 자동 인식·검색, 코드 `091230` 같은 앞자리 0 보존.
- 코드·상품명·기준일과 ETF 편입비중이 확인된 별도 자료의 종목 집중도·HHI·부분 비교.
- 구성비중 누락/비정상 값·중복·지원하지 않는 확장자 처리.
- CSV, XLSX, XLS 읽기 및 PDF 자동 수치 분석 제외.
- 출처 기록 Excel 다운로드(기존 분석 + 새 단독 분석).
- 업로드 상태는 **각 방문자의 Streamlit 세션**에만 저장하며, 서버 DB에 영구 저장하지 않습니다.

## 배포와 제약

GitHub `main` 브랜치의 `app.py`, `etf_engine.py`, `requirements.txt`, `README.md`를 같은 경로에서 교체하고, `tests/test_krx_marketcap.py` 등 테스트 파일을 보충합니다. 기존 Streamlit 앱 설정과 URL은 그대로 유지합니다. 자세한 내용은 `GitHub_업데이트_안내.md` 참조.

파일 최대 **15MB**, 한 번에 최대 **12개**, 서버 재시작 시 세션 자료가 사라질 수 있습니다. PDF 문서의 구성비중은 앱에서 분석하지 않습니다. 원본 데이터 이용약관을 준수해야 합니다.
