# ETF Insight — KRX 업로드 오류 개선형 무료 웹사이트

금융학술제 주제: **「펀드·ETF의 실질 기반 재분류 및 투자자 안내 방안 제안」**

이 ZIP은 사용자가 제공한 무료 웹버전 소스코드를 **보수적으로 개선**한 것입니다. 기존 GitHub 저장소와 Streamlit Community Cloud 무료 앱을 유지하도록 `app.py`를 실행 진입점으로 사용합니다. **원본 KRX 파일과 제3자 데이터를 ZIP에 포함하지 않습니다.**

## 웹사이트 이용자: 설치 없이 사용

1. 공개된 ETF Insight 웹사이트에 접속합니다.
2. KRX에서 받은 ETF 기본정보 목록 `.xlsx`를 업로드합니다.
3. `ETF 검색` 탭에서 상품명 또는 6자리 코드(영문 포함)를 검색합니다.
4. 편입종목·유효한 ETF 투자비중·ETF 식별정보·편입 기준일이 모두 확인되는 파일을 추가로 올리면 `실질분석` 또는 `유사 ETF 비교`를 사용할 수 있습니다.
5. `Excel 다운로드`에서 검증된 분석 결과를 다운로드합니다.

**자주 보는 결과**

- **ETF 기본정보**: ETF 상품명·코드·지수·운용사만 등록됩니다. 집중도는 아직 산출되지 않습니다.
- **미연결 구성종목**: 종목명·수량 등은 확인되지만 어느 ETF인지, 투자비중이 얼마인지 확인되지 않습니다. 해당 파일의 행 미리보기만 제공하며 어떤 ETF에도 붙이지 않습니다.
- **등록된 구성종목**: 확인 가능한 ETF 코드/이름/기준일/투자비중을 보유하는 자료에 한해서 분석 대상이 됩니다. 산업·국가·기업집단 정보는 공식 확인 전까지 생성하지 않습니다.

> 실제 KRX `data_0730_20261111.xlsx` 구조는 `시가총액 구성비중`이라는 열이 있지만 값은 모두 `-`입니다. **주식수·시가총액으로 누락된 ETF 순자산 대비 비중을 임의로 계산하지 않습니다.**

## 지원 포맷과 제한

- **XLSX, CSV, XLS**: 지원(실제 파일 형식도 확인).
- **PDF**: 업로드 선택은 가능하지만 표 해석 오류 가능성 때문에 등록하지 않으며, Excel/CSV 대체 안내를 표시합니다.
- 한 번에 **최대 12개**, 개별 파일 **15MB** 이하.
- 무료 서비스 특성상 앱 재시작 또는 브라우저 세션 종료 후 자료는 사라질 수 있습니다. 계정, 서버 DB, 영구 보관이 없습니다.
- 다른 방문자의 자료와 섞이지 않도록 Streamlit **세션 상태**에서만 데이터를 보관합니다. 다른 방문자가 업로드한 자료를 검색할 수는 없습니다.
- **업로드 파일을 제공기관으로 독립 검증하거나 KRX와 실시간 동기화하지 않습니다.** 해당 파일에 적힌 내용만 확인합니다.
- 공개된 데이터 이용조건을 확인하십시오. 민감정보를 업로드하지 마세요. 금융상품 매수·매도 권유가 아닙니다.

## 집중도·비교 산출 기준

- 주식 단일 종목 **20% 이상** 또는 상위 5종목 **70% 이상**: **고집중**
- 그 외 상위 3종목 **40% 이상**: **집중**
- 그 외: **분산**
- **HHI**: 구성자산 비중(%) 제곱의 합, **유효 구성항목 수** = 10,000 / HHI. 실제 비중이 99.95~100.05%인 자료는 계산용으로 100% 정규화하고 원본 합계도 별도 표시합니다.
- **종합 유사도 점수는 제공하지 않습니다.** 기존 연구 가중치(세부산업 40% / 보유종목 25% / 집중도 15% / 국가 10% / 기업집단 10%)를 계산할 공식 검증자료가 없기 때문입니다. 비중과 종목 식별자가 확보된 자료끼리만 구성종목 중복과 상위 5종목 격차를 확인합니다.
- 산업·국가·기업집단 분석은 공식 자료를 연결하기 전까지 **미확인**으로 남깁니다.

## 테스트: 개발자를 위한 정보 (웹 이용자는 불필요)

```bash
python -m pip install -r requirements.txt pytest
python -m pytest -q tests
```

파일 3개를 직접 보유한 경우, 테스트 시 `KRX_CATALOG_FILE`, `KRX_HOLDINGS_FILE`, `KRX_PDF_FILE` 환경변수에 각 파일 경로를 설정하면 `tests/test_actual_krx_optional.py`의 통합 테스트를 추가로 실행합니다. 이 파일이 없는 경우 해당 테스트는 건너뜁니다.

**현재 검증:** 이전 테스트 14개 / 수정 후 실제 KRX 원본 검증 3개 포함 총 30개 통과. 엔진과 테스트 실행 및 구문 컴파일은 확인했지만, 테스트 환경에 Streamlit이 없어서 앱 서버 실행·브라우저 자동화·실제 배포는 확인하지 못했습니다. 완료 여부는 `전체오류_수정결과.md`를 참고하세요.
